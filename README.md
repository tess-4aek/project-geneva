# Project GENEVA  
### _Prototype Phase — Godot 4 (2D Action / Roguelite / Sci-Fi)_

---

## 📌 О проекте
**Project Synthia** — 2D sci-fi action-roguelite, где учёный после падения цивилизации выращивает поколения био-андроидов-дочерей.  
Игрок сочетает генетические мутации, протезирование, боевые модули и прогрессию дрона, чтобы исследовать опасные зоны, сражаться с врагами и развивать своё базовое убежище.

Игра сейчас находится на **ранней стадии прототипирования**: создаются базовые системы движения, боёвки и поведения врагов.

---

## 🎮 Основной игровой цикл
1. **Создание/прокачка андроида** в базе (инкубатор + мутации + протезы)  
2. **Вылазка в заражённые / охраняемые зоны**  
3. **Бой + исследование** (уклонение, атаки, комбо, дрон-поддержка)  
4. **Сбор ресурсов, данных и образцов**  
5. **Возвращение на базу**, развитие модулей, создание нового поколения  

---

## 🧬 Ключевые механики (план)
- Передвижение, уклонение с i-frame  
- Быстрая и сильная атака  
- Парирование  
- Комбо-система  
- Дрон (мирный/боевой режим, пассивки, КД)  
- Генетические модификации (био-мутанты)  
- Протезирование (техно-лаба)  
- Инкубатор поколений (наследование характеристик)  
- Модули базы (апгрейд лабораторий)  
- Система фракций (люди, роботы, мутанты)  
- Стелс/шум/реакция NPC на внешний вид  
- Босс-файты по типу Stellar Blade (в 2D)
